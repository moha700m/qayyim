# قيِّم

موقع عربي يستخرج **رابط تقييمات قوقل** من رابط المشاركة في خرائط قوقل.

- الصق `maps.app.goo.gl` أو الرابط الكامل
- تحصل على رابط كتابة التقييم، ورابط مشاهدة التقييمات، ومعرّف المكان، وباركود

## النشر على Vercel

1. افتح [vercel.com/new](https://vercel.com/new)
2. استورد هذا المستودع
3. اترك أمر البناء `npm run build`
4. انشر

لا يحتاج قاعدة بيانات ولا مفاتيح قوقل.
